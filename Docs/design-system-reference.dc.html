Design system · iOS 17 · SwiftUI

FoodScannerUI

FoodScanner's visual language in code: two seasonal palettes, the official Nutri-Score, patterns that double every color, and six food mascots. One page, two levels of reading.

Local Swift package FS prefix Primitives in, always Zero dependencies
Rule 1

The Nutri-Score never follows the theme. Official flat colors in both light and dark, black lettering on the yellow C only.

Rule 2

No information is carried by color alone: every nutrient has its pattern, every score its written letter.

Rule 3

Body text at 19 pt minimum, tap targets at 44 pt minimum, Dynamic Type up to AX5 on every component.

Increased contrast

Driven by the real system signal @Environment(\.colorSchemeContrast) — no in-house switch. The Nutri-Score stays unchanged; controls thicken their border and switch to two dedicated tokens.

fsBorderStrong

Near-ink border for controls (buttons, keypad, barcode field) under increased contrast.

fsAccentSoftStrong

Reinforced tinted fill — distinguishes the keypad's "delete" key from the numeric keys under increased contrast.

@Environment(\.fsResolvedContrast) private var contrast   // system OR preview override

FSMetrics.borderWidth(for: contrast)          // standard thickness
FSMetrics.borderWidthStrong(for: contrast)    // thickness for filled buttons
.fsCard()                                     // FSCardModifier, contrast-aware
 
FSGalleryView()
    .fsSeason(.autumnWinter)        // forced on this subtree
    .fsSeasonFollowsCalendar()      // or derived from the real month

Atoms and molecules

Every component takes primitives — no Realm model ever crosses the module boundary.

Atoms
FSButton — pill, 3 roles, 60 pt FSIconButton — icon only, label required FSTag — neutral / leaf / alert chip FSScoreBadge, FSScoreScale FSBarcodeField, FSKeypad FSToggleRow, FSTextSizeSlider FSPattern, FSPatternSwatch FSMascot, FSMascotRow FSStatusRow — read-only system row

Installation

1Copy FoodScannerUI/ next to FoodScanner.xcodeproj.
2Xcode → File ▸ Add Package Dependencies… ▸ Add Local… → select the folder.
3Target FoodScanner → General ▸ Frameworks, Libraries and Embedded Content → add FoodScannerUI.
4import FoodScannerUI, then present FSGalleryView() inside a UIHostingController for the full showcase.

The app finished its screen-by-screen migration off UIKit; every screen is pure SwiftUI today (see the app-level CLAUDE.md for the current architecture).
