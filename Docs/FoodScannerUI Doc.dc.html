FoodScannerUI

La charte de FoodScanner en code : deux palettes saisonnières, le Nutri-Score officiel, des motifs qui doublent chaque couleur, et six mascottes-aliments. Une page, deux niveaux de lecture.

Package Swift local Préfixe FS Primitives en entrée Aucune dépendance
Règle 1

Le Nutri-Score ne suit jamais le thème. Aplats officiels en clair comme en sombre, lettre noire sur le C jaune uniquement.

Règle 2

Aucune information portée par la couleur seule : chaque nutriment a son motif, chaque score sa lettre écrite.

Règle 3

Corps de texte à 19 pt minimum, cible tactile à 44 pt minimum, Dynamic Type jusqu'à AX5 sur tous les composants.

Les deux saisons

Le thème clair emprunte aux aliments de printemps et d'été, le thème sombre à ceux d'automne et d'hiver. FSSeason a deux cas et suit le ColorScheme par défaut.

Installation

1Copier FoodScannerUI/ à côté de FoodScanner.xcodeproj.
2Xcode → File ▸ Add Package Dependencies… ▸ Add Local… → sélectionner le dossier.
3Cible FoodScanner → General ▸ Frameworks, Libraries and Embedded Content → ajouter FoodScannerUI.
4import FoodScannerUI, puis présenter FSGalleryView() dans un UIHostingController pour la recette.

La migration écran par écran de l'app UIKit est décrite dans MIGRATION.md, avec le tableau des correspondances et l'exemple de la fiche produit.
